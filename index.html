[0x01] HASHING (SHA-256)

A criptografia hash cria uma "impressão digital" única e irreversível do dado original.

-- AGUARDANDO ENTRADA --

Código Python para Google Colab:

import hashlib

texto = "SenhaSecreta123"

# Gerando o Hash SHA-256
hash_obj = hashlib.sha256(texto.encode())
hash_hex = hash_obj.hexdigest()

print(f"Texto Original: {texto}")
print(f"Hash SHA-256  : {hash_hex}")

from cryptography.fernet import Fernet

# 1. Gerar Chave Secreta
chave = Fernet.generate_key()
cipher = Fernet(chave)

# 2. Cifrar e Decifrar
mensagem = "Mensagem Ultra Secreta".encode()
mensagem_cifrada = cipher.encrypt(mensagem)
mensagem_decifrada = cipher.decrypt(mensagem_cifrada).decode()

print(f"Chave Gerada    : {chave.decode()}")
print(f"Texto Cifrado   : {mensagem_cifrada.decode()}")
print(f"Texto Decifrado : {mensagem_decifrada}")

[0x03] GUIA DE PROTEÇÃO & BOAS PRÁTICAS

Métodos fundamentais para proteger informações e garantir a segurança no desenvolvimento de sistemas:

  • 1. Proteção de Senhas com Hash e Salt

    Nunca salve senhas em texto puro. Armazene apenas o hash da senha combinada com um valor aleatório (salt) para mitigar ataques de dicionário e tabelas Rainbow.

  • 2. Criptografia em Trânsito (HTTPS/TLS)

    Sempre transite informações sensíveis utilizando protocolos cifrados para impedir a interceptação de dados na rede (Ataques Man-in-the-Middle).

  • 3. Gestão Segura de Chaves Criptográficas

    Não inclua chaves secretas diretamente dentro do código-fonte (hardcoding). Utilize variáveis de ambiente ou cofres de credenciais (Key Vaults).

  • 4. Validação de Integridade de Arquivos

    Utilize hashes para verificar se um arquivo baixado ou transferido não foi alterado ou corrompido durante a transmissão.

Exemplo em Python: Validação de Integridade no Colab

import hashlib

def verificar_integridade(caminho_arquivo, hash_esperado):
    sha256 = hashlib.sha256()
    with open(caminho_arquivo, 'rb') as f:
        while chunk := f.read(8192):
            sha256.update(chunk)
    
    hash_calculado = sha256.hexdigest()
    return hash_calculado == hash_esperado, hash_calculado

# Criando arquivo de teste no Colab
with open("arquivo_teste.txt", "w") as f:
    f.write("Conteudo confidencial intacto.")

# Teste de verificação
hash_original = "13b6326dd28eb675c8893bd596dc5b497f6c3eb9ad483ef3c7bdcdca5081fdfc"
is_valido, hash_atual = verificar_integridade("arquivo_teste.txt", hash_original)

print(f"Hash Calculado   : {hash_atual}")
print(f"Arquivo Íntegro? : {is_valido}")
